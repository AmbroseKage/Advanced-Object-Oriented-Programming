# Advanced Object-Oriented Programming – Practice Projects

This repository contains a collection of my implementations from the **Advanced Object-Oriented Programming** course, where I explore real-world problems using OOP techniques in **C++** and **Python**.

The projects cover topics such as graph theory algorithms, client-server modeling, factory simulations, and the Traveling Salesman Problem (TSP). Each task was designed to deepen understanding of data structures, object composition, memory management, and modular code architecture.

---

## 📁 Project Overview

| Folder / Task | Description |
|---------------|-------------|
| `graphs/` | Implementations of classic graph algorithms like **BFS** and **Dijkstra**, with adjacency list/matrix representations. |
| `relationships-between-classes/` | UML-based designs and code examples of class relationships: **composition**, **aggregation**, and **inheritance**. |
| `smart-pointers/` | C++ examples of using `unique_ptr`, `shared_ptr`, and `weak_ptr` to manage memory safely and efficiently. |
| `servers/` | Python modeling of a server-client system managing a collection of products, using object-oriented design. |
| `tsp/` | C++ implementation of **Little’s algorithm** to solve the **Traveling Salesman Problem** using cost matrix optimization. |
| `netsim/` | A full simulation of a **factory production network** in C++, involving loading ramps, workers, and warehouses. It includes:
- Product flow through various stages (FIFO / LIFO)
- Randomized routing logic
- Round-based time simulation and reporting |

---

## 🔍 Key Concepts Covered

- Breadth-First Search (BFS) and shortest path algorithms (Dijkstra)
- Graph representations: adjacency lists and weighted matrices
- Class design: inheritance, polymorphism, encapsulation
- Memory-safe programming with modern C++ smart pointers
- Simulation design with sequential processing and state management
- Object-oriented modeling and UML diagram logic
- Efficient handling of complex algorithms (e.g. TSP optimization)
